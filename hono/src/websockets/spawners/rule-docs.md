# Rules

## Namespace
`Time`

### Example
- `Time:DaySegment > early morning`
- `Time:Season == winter`
- `Time:Clock > 9:00am`

## Clock
### Operators
- `>=`
- `<=`

### Examples
- `<= 9am`

## DaySegment
### Operators
- `==`
- `!=`
- `<=`
- `>=`

### Example Segments
- **Early Morning** (5 to 8): `earlyMorning`
- **Morning** (8 to 12): `morning`
- **Afternoon** (12 to 17)
- **Evening** (17 to 21)
- **Night** (21 to 00)
- **Late Night** (00 to 3)

## Season
### Operators
- `==`
- `!=`

### Examples
- Winter
- Spring
- Summer
- Fall
